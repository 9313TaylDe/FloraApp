# 🌿 FloraApp

FloraApp é um aplicativo Android desenvolvido em Kotlin com Jetpack Compose, focado no gerenciamento e cuidados com plantas.

---

## ✨ Funcionalidades

- Listagem de plantas
- Detalhes de cada planta
- Adicionar novas plantas
- Editar plantas
- Favoritos
- Navegação entre telas (Navigation Compose)
- Interface moderna com Material 3

---

## 🧠 Tecnologias

- Kotlin
- Jetpack Compose
- Material 3
- Navigation Compose
- MVVM
- ViewModel
- Coroutines / StateFlow

---

## 🏗️ Arquitetura

O projeto segue o padrão MVVM:

- UI (Compose)
- ViewModel
- Model
- Repository
